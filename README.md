# 🌦️ Weather App (Python)

A simple and user-friendly **Weather Application** built using **Python** and the **WeatherAPI**. This application allows users to get real-time weather information for any city around the world directly from the terminal.

---

## 🚀 Features

- 🌍 Search weather by city name
- 🌡️ Current temperature
- 🤒 Feels like temperature
- ☁️ Weather condition
- 💧 Humidity
- 🌬️ Wind speed
- 🧭 Wind direction
- 👁️ Visibility
- 🌡️ Air pressure
- ☀️ UV Index
- 🕒 Local time
- 🌎 Country information
- ❌ Invalid city handling
- 🌐 Internet connection error handling

---

## 🛠️ Technologies Used

- Python 3
- Requests Library
- WeatherAPI

## 📦 Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/Weather-App-Python.git
```

### 2. Open the project folder

```bash
cd Weather-App-Python
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

---

## 🔑 API Key Setup

This project uses **WeatherAPI**.

1. Create a free account at:
   https://www.weatherapi.com/

2. Generate your API Key.

3. Open `weather.py` and replace:

```python
API_KEY = "YOUR_API_KEY"
```

with

```python
API_KEY = "YOUR_ACTUAL_API_KEY"
```

## ▶️ Run the Project

```bash
python weather.py
```
